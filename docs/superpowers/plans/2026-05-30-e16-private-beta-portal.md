# E16 — Private Beta Portal — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gate the whole platform behind invite-only access during beta (`BETA_MODE`), let founding members mint shareable invites with a quota, capture a public waitlist + in-product feedback — all flippable off at launch with no rip-out.

**Architecture:** A `BetaMode` config flag drives a `beta.Gate` middleware (mounted after `auth.Middleware`) that 403s non-beta users on protected route groups; the allowlist is *structural* (public groups simply don't mount the gate). `users.is_beta` is the DB-authoritative membership flag (mirrors `is_admin`). Invites live in `beta_invites` with race-safe redemption (conditional `UPDATE ... WHERE used_count < max_uses`), redeemed in the same transaction as signup. Feedback + waitlist are simple owned/idempotent tables.

**Tech Stack:** Go 1.22 (chi, pgx, sqlc), Postgres, Next.js middleware, Vitest e2e against the docker-compose stack.

**Spec:** `docs/superpowers/specs/2026-05-30-e16-private-beta-portal-design.md`
**Tracking epic:** E16 (GitHub issue TBD)

    max_uses    int         NOT NULL DEFAULT 1,

  ADD COLUMN invited_by  uuid REFERENCES users(id),

    id         uuid        PRIMARY KEY DEFAULT gen_random_uuid(),

    kind       text        NOT NULL,
    body       text        NOT NULL,
    status     text        NOT NULL DEFAULT 'new',
    admin_note text,
    created_at timestamptz NOT NULL DEFAULT now(),

    CHECK (status IN ('new','triaged','done'))

INSERT INTO beta_invites (code, created_by, cohort, max_uses, expires_at)

RETURNING *;

-- name: RedeemBetaInvite :one
UPDATE beta_invites
   SET used_count = used_count + 1
 WHERE code = $1
   AND used_count < max_uses
   AND (expires_at IS NULL OR expires_at > now())
RETURNING id, cohort, created_by;

-- name: ListBetaInvites :many
SELECT * FROM beta_invites ORDER BY created_at DESC;

-- name: ListBetaInvitesByCreator :many
SELECT * FROM beta_invites WHERE created_by = $1 ORDER BY created_at DESC;

-- name: CountBetaInvitesByCreator :one

```go
package beta

import (
	"log/slog"
	"net/http"

	"github.com/jackc/pgx/v5/pgxpool"

	"github.com/sniffins-mcmuggins/render/api/internal/auth"
	"github.com/sniffins-mcmuggins/render/api/internal/config"
	"github.com/sniffins-mcmuggins/render/api/internal/httperr"
	"github.com/sniffins-mcmuggins/render/api/internal/sqlcdb"
)

// Gate blocks non-beta users when BetaMode is on. Mount AFTER auth.Middleware.
// Reads is_beta live from the DB (never the JWT claim) — same rule as RequireAdmin.
func Gate(cfg config.Config, pool *pgxpool.Pool) func(http.Handler) http.Handler {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			if !cfg.BetaMode {
				next.ServeHTTP(w, r)
				return
			}
			p := auth.User(r.Context())
			if p == nil {
				httperr.Unauthorized(w)
				return
			}
			u, err := sqlcdb.New(pool).GetUserByID(r.Context(), p.UserID)
			if err != nil || !u.IsBeta {
				httperr.Forbidden(w, "beta access required")
				return
			}
			next.ServeHTTP(w, r)
		})
	}
}
```

2. Begin a `pool.Begin(ctx)` tx; `q := sqlcdb.New(tx)`.
