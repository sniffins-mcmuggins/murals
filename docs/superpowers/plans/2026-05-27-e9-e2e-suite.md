# E9 — E2E Test Suite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the full E9 e2e suite — a Vitest API golden-path test and four Playwright browser specs — all running against the docker-compose stack with API-managed test data.

**Architecture:** Two runners share `e2e/fixtures/helpers.ts`. Vitest handles `e2e/api/` (no browser, fast CI gate). Playwright handles `e2e/browser/` (Chromium only). Neither runner starts the stack — `task up && task db:migrate` is a precondition. All write-path tests create isolated data via API helpers in `beforeAll`; no seed data dependency.

**Tech Stack:** `@playwright/test ^1.49`, `vitest ^3`, Node built-in `fetch`, `@render/api-client` types, Go API at `localhost:8080`, Next.js web at `localhost:3000`, MinIO at `localhost:9000`.

---

## Key facts (read before implementing)

- **Auth:** `POST /auth/signup` returns `{ id, email, role, created_at }` (no token). `POST /auth/login` returns `{ token, user }` and sets an HTTP-only `session` cookie scoped to `localhost` (port-agnostic — shared between :3000 and :8080).
- **Presign URL rewrite:** The API's `POST /images/presign` returns an `uploadUrl` containing `http://minio:9000` (internal Docker hostname). Tests running on the host must rewrite this to `http://localhost:9000` before PUTting to it.
- **Images confirm:** `POST /images/confirm` body is `{ s3Key }` only. Returns `{ cdnUrl }`.
- **Collection cover:** The public artist page (`/artists/{id}`) shows `collection.cover_s3_key` as the cover image. The `uploadImage` helper must also PATCH the collection with `{ coverS3Key }` so the image appears on the public page.
- **Festival status:** The public map endpoint (`GET /festivals/slug/{slug}/map`) only returns pins for `live` festivals. The UI only lets organisers toggle between `draft` and `open`. Setting `live` requires a direct API call.
- **Application form:** No form editor UI exists. Form setup is always done via the `upsertForm` API helper.
- **Signup form:** Has a role `<select>` — options "Artist" (`artist`) and "Festival organiser" (`organiser`).
- **Map editor selectors:** Artist dropdown `#artist-select`, W3W input `#w3w-input`, save button text "Save pin".
- **Apply page:** Form `aria-label="Application form"`, submit button text "Submit application", success heading text "Application submitted".
- **`page.request`:** Playwright's `page.request` carries the browser context's cookies, so `page.request.get('http://localhost:8080/...')` works after UI login (cookies are shared for `localhost`).

export async function uploadImage(
  token: string,
  collectionId: string,
): Promise<{ imageId: string; cdnUrl: string; s3Key: string }> {
  // 1. Presign
  const presignRes = await fetch(`${API}/images/presign`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${token}` },
    body: JSON.stringify({ contentType: 'image/jpeg' }),
  })
  if (!presignRes.ok) throw new Error(`Presign failed: ${presignRes.status}`)
  const { uploadUrl, s3Key } = await presignRes.json()

  // 2. Rewrite internal Docker URL to host-accessible URL
  const hostUploadUrl = (uploadUrl as string).replace('http://minio:9000', 'http://localhost:9000')

  // 3. PUT to MinIO
  const putRes = await fetch(hostUploadUrl, {
    method: 'PUT',
    headers: { 'Content-Type': 'image/jpeg' },
    body: MINIMAL_JPEG,
  })
  if (!putRes.ok) throw new Error(`MinIO PUT failed: ${putRes.status}`)

  // 4. Confirm
  const confirmRes = await fetch(`${API}/images/confirm`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${token}` },
    body: JSON.stringify({ s3Key }),
  })
  if (!confirmRes.ok) throw new Error(`Confirm failed: ${confirmRes.status}`)
  const { cdnUrl } = await confirmRes.json()

  // 5. Attach to collection
  const attachRes = await fetch(`${API}/collections/${collectionId}/images`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${token}` },
    body: JSON.stringify({ s3Key, cdnUrl }),
  })
  if (!attachRes.ok) throw new Error(`Attach image failed: ${attachRes.status}`)
  const imageData = await attachRes.json()

  // 6. Set as collection cover so it appears on the public artist page
  await fetch(`${API}/collections/${collectionId}`, {
    method: 'PATCH',
    headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${token}` },
    body: JSON.stringify({ coverS3Key: s3Key }),
  })

  return { imageId: imageData.id, cdnUrl, s3Key }
}
